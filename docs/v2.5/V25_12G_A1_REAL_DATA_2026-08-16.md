## Frame-metadata caveat

One metadata inconsistency was observed:

```text
derivation.yaml frame_id = source_map
aisle_graph.yaml frame_id = map
site_boundary.yaml frame_id = map
vehicle_feasible_segments.yaml frame_id = map
```

Code-path review showed that the current Navigation Map is derived directly in the loaded PCD numeric coordinate system and the Workbench navigation export writes `source_map` as a metadata label, while agricultural aisle geometry is generated directly from the same Navigation Grid numeric coordinates and defaults its metadata label to `map`.

No additional rigid transform was identified in this path, and the real Workbench overlay showed no gross geometric misalignment. This is therefore recorded as a frame-metadata consistency issue, not as evidence of an A1 geometry transform error.

It should be corrected separately before treating frame labels as independently reliable provenance.

## Frozen sensitivity probe

A diagnostic-only sensitivity probe was run on the same real data. It did not modify A1 outputs or defaults.

For each blocked longitudinal sample, the probe compared:

```text
frozen configuration
= Site Boundary enabled + preview footprint padding 0.05 m

no-boundary probe
= same frozen configuration but Site Boundary omitted

no-padding probe
= same frozen configuration but preview footprint padding set to 0.00 m
```

This probe is explanatory evidence only. It does not authorize either alternative as a production configuration.

### Aggregate blocked-sample sensitivity

Across the five diagnostic aisles there were 277 blocked longitudinal samples in the frozen trace.

```text
                           blocked   recovered if no boundary   recovered if no extra padding
aisle_016                    17                  3                         9
aisle_017                    62                  5                        42
aisle_018                    58                  0                        23
aisle_019                   126                 37                        73
aisle_020                    14                  0                         1
TOTAL                       277                 45                       148
```

Removing Site Boundary alone recovered 45 / 277 blocked samples in this counterfactual probe.

Removing only the extra 0.05 m preview padding recovered 148 / 277 blocked samples.

The two sensitivities overlap and must not be added as independent causal categories. Nevertheless, padding sensitivity is substantially broader than Site Boundary sensitivity in this diagnostic subset.

### Important aisle observations

`aisle_016` contains several isolated padding-sensitive failures around the active-segment boundaries, while the low-U end also has limited Site Boundary sensitivity.

`aisle_017` shows strong padding sensitivity: 42 of its 62 blocked samples become feasible in the zero-extra-padding counterfactual, compared with 5 in the no-boundary counterfactual. The large fragmented representation is therefore strongly coupled to current footprint/padding/grid semantics.

`aisle_018` has no Site Boundary-limited samples in the frozen trace. Its observed sensitivity is entirely on the padding/grid side in this probe.

`aisle_019` is the strongest mixed case. Site Boundary sensitivity is material near the low-U side, but the no-padding probe recovers 73 of 126 blocked samples, including many interior failures. The long fragmented region therefore cannot be attributed to Site Boundary alone.

`aisle_020` remains the stable control. Only 1 of 14 blocked endpoint samples is recovered by removing extra padding and none are recovered by removing Site Boundary.

## Interpretation

The real-data experiment supports the central A1 design decision:

```text
whole aisle as the only planning primitive
-> loses useful feasible geometry

all maximal contiguous feasible runs
-> preserves materially more auditable vehicle-feasible geometry
```

The strongest evidence is `aisle_016` and `aisle_017`, where A1 preserves approximately 11.57 m and 11.08 m respectively beyond the legacy longest-only representation without changing the frozen feasibility gates.

The experiment also confirms that A1 is not the component responsible for the dominant fragmentation. The shared feasibility trace is exposing upstream configuration-space evidence. On this dataset, extra footprint padding and Navigation Grid / base-footprint interaction remain more influential than Site Boundary across the diagnostic subset, while Site Boundary remains a valid hard safety invariant and is locally important in `aisle_016`, `aisle_017`, and especially the low-U side of `aisle_019`.

Therefore the correct outcome is:

```text
A1 SEGMENT REPRESENTATION SUPPORTED WITH MAP/FOOTPRINT CAVEATS
```

not:

```text
REMOVE SITE BOUNDARY
REMOVE PADDING
PROMOTE A1 TO ROUTE READY
```

The sensitivity probe does not justify changing the frozen 0.05 m padding. It identifies where a later map/footprint calibration study should focus.
