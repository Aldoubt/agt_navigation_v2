# Historical Records

This directory contains historical migration, experiment, and project-planning
records. Files under `docs/archive/` are not authoritative descriptions of the
current runtime architecture or interface contracts.

Current architecture and interfaces are defined by `docs/architecture/`,
`docs/interfaces/`, and `docs/roadmap/`. Archive documents may retain old
Phase/TASK labels, hashes, benchmarks, calibration results, and migration facts
as historical evidence.
