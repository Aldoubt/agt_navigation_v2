# Bunker 二维可通行性对照实验（2026-07-20）

## 范围与结论

输入为 `mapping_20260719_172810` 大包和 `bunker_large_20260719` 射线基图。实验直接读取
8,073 帧注册点云与 8,072 个里程计位姿，一次生成地面、时序动态和高度分层三组地图，
均应用 canonical Bunker 多边形完整扫掠。结果仅用于离线解释，不改变正式导航地图。

保守推荐是继续人工核验 `ground_temporal`。时序过滤对最终 occupied 只减少 2,270 个
像素，而 provisional 高度分层减少 72,631 个，说明本场景地图差异主要来自高层结构，
不是动态拖影。整车含 MID360 的最高点尚未实测，所以分层图不得执行。
