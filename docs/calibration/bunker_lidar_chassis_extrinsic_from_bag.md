# 使用现有 bag 标定 BUNKER–MID360 外参

## 结论

现有 bag 可以用于改进当前粗测外参，但不能仅凭履带底盘平面里程计无约束地精确求出完整
六自由度。推荐把问题拆成：

- 用底盘里程计与 LIO 相对运动做平面 hand-eye，估计 `x/y/yaw` 和时间偏移；
- 用静止 IMU 重力与多处地面平面约束 `roll/pitch`；
- 用地面平面、雷达中心实测离地高度和 `base_link` 基准约束 `z`；
- 在未参与优化的 bag 和实测场地上验证后，才设置 `calibration_verified: true`。

履带打滑会污染轮速里程计，因此优化必须采用鲁棒损失、剔除静止/打滑异常段，并把结果
视为待实车验证的初值，而不是机械测量真值。

## 可观测性与采集要求

纯平面、恒速直行不能稳定区分所有外参。主标定片段应同时包含多段直行、明显的左/右转、
不同角速度和短距离反向，且环境中有固定的立面与地面。原地履带转向滑移最大，可用于角度
激励但必须降低轮速约束权重。静止片段用于重力和时间戳检查。

若现有大包缺少这些激励，应补录 2–5 分钟专用标定 bag，而不是强行从弱可观测数据求解。

## 建议求解与验收流程

1. 从两个 odometry topic 提取按时间对齐的相对位姿，先估计时间偏移并检查频率/跳变。
2. 对满足最小平移和旋转激励的运动对求解平面 `A X = X B`，使用 Huber/Cauchy 鲁棒损失；
   分别报告直行、转弯和疑似打滑残差。
3. 从多个静止区间估计重力方向，并从不同位置的注册点云拟合地面；联合约束
   `roll/pitch/z`。MID360 内部 IMU–LiDAR 厂定外参必须按驱动/FAST-LIVO 配置一致解释。
4. 将候选值写入 `src/agt_description/config/bunker_mid360.yaml`，保持
   `calibration_verified: false`，重放主包检查点云重影、地面厚度和轨迹残差。
5. 不再调参，重放 16:32 验证包；再用卷尺/水平仪核对安装方向与高度，并做真实导航地图
   重定位测试。只有验证误差门限明确且通过，才批准替换粗测值和置为 verified。

## 当前粗测基线

当前文件表示 `base_link -> lidar_link`：`x=0.2615 m`、`y=0`、`z=0.3000 m`、
`roll=0`、`pitch=+0.5235987756 rad`、`yaw=0`。其中 `base_link_z=0.200 m` 仍是临时基准，
因此雷达中心离地 0.500 m 与 `lidar_z=0.300 m` 并不矛盾。标定脚本必须读取配置，不能把
用户名、工作区或 bag 路径写死。

目前仓库尚未实现上述离线优化器；下一步应先实现数据提取、时间对齐、激励检查和报告，
再增加求解，避免一次处理 8.4 GiB bag 时重新触发内存耗尽。
